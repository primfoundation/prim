# ORF protocol

This repository is **spec + validator + examples only**. Do not dump research packs here.

- Spec: `SPEC.md`
- Validate: `python3 -m orf.validate` or `orf-validate`
- Packs live next to the work (default Squiddie `.research/<id>/`)
- Sibling profiles: EMF, OPF, ODFW, okflify — see README composition tree
- Squiddie is a **consumer** that produces ORF packs; protocol authority is this repo
