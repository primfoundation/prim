# Goldfish memory — weeks, not three seconds

## In a nutshell

The “3-second goldfish memory” claim is folklore. Controlled work shows learning retained for weeks to months. This pack is an **ORF** example, not a full Squiddie run.

## Answer

Goldfish memory lasts far longer than three seconds; treat the slogan as myth unless primary evidence appears.
