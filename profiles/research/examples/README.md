# An investigation handoff example

This is an acceptance scenario, not a validated Research vNext file.

Question: Did a supplier change its stated lead time?

Worker A retains a dated supplier notice and a saved earlier product page. It
records that the notice states a new lead time. It does not claim the supplier's
actual fulfillment performance changed. Worker B finds that a reseller copied
the notice; the reseller is not counted as independent corroboration. Worker B
also records an unresolved disagreement with a purchase-order acknowledgement.

The two workers preserve the question, source lineage, the disputed claim,
source locations, dates, and remaining uncertainty. A report can summarize the
result without discarding the contradiction. Later, another worker can refresh
the sources without overwriting the historical investigation.

Acceptance requires two actual implementations and retained artifacts. No such
interoperability pass is claimed by the existence of this scenario.
