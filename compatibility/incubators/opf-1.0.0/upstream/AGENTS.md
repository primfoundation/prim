# Open Product Format v1

OPF is the canonical durable product graph, not a Markdown profile.

- `product.json` is semantic authority; files and folders are projections.
- Keep entities stable, relationships typed, and containment singly rooted and explicitly ordered.
- Preserve product intent, outcomes, experience, decisions, work, evidence, proof, authority, gaps, lifecycle, and events as first-class records.
- Never infer hierarchy from filenames, links, graph degree, or dates.
- Never infer temporal subjects from prose; empty historic log subjects stay visibly unresolved.
- Keep the validator standard-library-only and fail closed.
- Run validation before rendering or publication.
- OPF v1 has no v0 compatibility path.
