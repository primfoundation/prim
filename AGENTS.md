# Prim Foundation contributor handoff

Read program/README.md, CHARTER.md, DECISIONS.md, BASELINE.md, and HANDOFF.md before changing the program. These paths are under program/ unless otherwise stated.

Preserve existing formats, consumers, private data, and unrelated branches. A profile is not a repository; a standard is not an agent runtime; a source file is not its claims. Knowledge, capability, authority, structural conformance, security review, and factual truth are separate.

Keep program/plan.json authoritative for status; generate ROADMAP.md. Cite requirement IDs in changes. Completion needs each requirement's declared evidence stages, exact test scope, and retained limitations. Never mark deployment or real-use verification from a local test.

Run the checks in program/README.md. Record exact next steps, blockers, and unresolved choices. Do not expose credentials or private records in the public repository. Never automatically execute discovered profile code. Do not force-push, archive repositories, or change production as cleanup. Governance, spending, sensitive access, and destructive changes require explicit authorization.
